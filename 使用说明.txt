营销 Agent 离线演示版

打开方式
1. 解压整个“营销Agent离线版”文件夹。
2. 双击“启动营销Agent.command”。
3. 浏览器会自动打开离线演示页。
4. 使用期间请保留启动窗口；关闭窗口或按 Control + C 即可停止。

可离线使用
- 首页、Agent 对话框、妙招分类与卡片
- 自定义妙招、引用标签、收藏、编辑和删除
- 批量基建的三类提示词与下拉引用组件
- 白模视频、素材确认组件和 Agent 待办演示
- 本地项目、草稿、收藏等浏览器内数据

说明
- 无需安装项目依赖，仅需 macOS 自带或本机已有的 Python 3。
- 页面只在本机 127.0.0.1 运行，不会向外网发送请求。
- 真实广告账户、在线数据查询、发布和真实视频生成需要业务服务，离线版仅保留这些页面的演示交互。
- 首次打开是独立的本地数据空间，不包含其他浏览器地址中已经保存的草稿。
