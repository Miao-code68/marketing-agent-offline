# 营销 Agent 离线演示版

这是营销 Agent 网页原型的离线版本，包含首页场景、批量基建、自定义妙招、白模视频、Agent 待办和智能投放等交互。

## 使用方法

### macOS

1. [下载营销Agent离线版.zip](release/营销Agent离线版.zip) 并解压。
2. 双击 `启动营销Agent.command`。
3. 浏览器会自动打开离线网页。

如果 macOS 首次阻止运行，可在“系统设置 → 隐私与安全性”中允许，或右键启动文件后选择“打开”。

### Windows / Linux

进入解压后的目录，运行：

```bash
python3 离线启动器.py
```

随后浏览器会自动打开本地网页。

## 说明

- 页面与资源均保存在本地，启动后通过本机地址访问。
- 演示数据保存在浏览器本地，不会连接真实广告账户或执行真实发布。
- 为保证本地数据、脚本和资源正常加载，请使用启动器，不要直接双击 `index.html`。
- 默认地址为 `http://127.0.0.1:18766`；端口被占用时，启动器会自动选择可用端口。

## 目录

- `index.html`：网页入口
- `assets/`：演示数据和静态资源
- `离线启动器.py`：跨平台本地启动器
- `启动营销Agent.command`：macOS 双击启动文件
- `使用说明.txt`：简明使用说明
- `release/营销Agent离线版.zip`：可直接下载分发的完整离线包
